# Guias de prestação de contas PPI 4.0

Materiais de referência para analistas de P&D de instituições executoras de projetos do Programa Prioritário de Indústria 4.0 e Modernização Industrial (PPI 4.0), coordenado pelo CITS.

| Guia | Conteúdo |
|---|---|
| [Guia de prestação de contas](guias/guia-prestacao-de-contas.html) | Rotina do analista, obrigações, dependências entre áreas, fluxogramas, SIPOC, matriz RACI, jornada operacional e fluxo end-to-end |
| [Manual das ferramentas](guias/manual-das-ferramentas.html) | Planilha Financeira Mensal, Indicadores Gerenciais e Relatório Demonstrativo: preenchimento, prints anotados dos modelos, leitura crítica dos indicadores e checklist mensal |
| [Base normativa de PD&I](guias/base-normativa-pdi.html) | Leis, decretos, resoluções, portarias e manuais do PPI 4.0 e do convênio direto, com botões para o texto oficial |

## Como usar

Cada guia é um único arquivo `.html`, com imagens e diagramas embutidos. Abra no navegador, direto do repositório baixado ou pelo GitHub Pages, se estiver ativado. Todos têm botão para alternar entre modo claro e escuro.

## Observações

- O conteúdo foi elaborado a partir dos modelos e orientações de prestação de contas do PPI 4.0 e de material de referência normativo. Itens marcados como premissa ou lacuna devem ser validados com a coordenadora e com o instrumento de cada projeto.
- Os links normativos apontam para Planalto, Diário Oficial da União e Suframa. Confira o texto oficial antes de citá-lo em documento.
- Este material não substitui parecer jurídico.
